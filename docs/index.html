Privacy promise

The blocker is intentionally small.

Chrome blocks locally

The extension uses Manifest V3 declarative rules, so Chrome applies blocking without the extension reading page contents.

Only minimal permissions

It avoids host permissions, browsing history permissions, cookies, tabs, content scripts, and account sign-in.

Open source by design

The rules, scripts, and privacy policy are visible in the repository so users can inspect what the extension does.

Blocked by default

Short-form destinations, not your whole browser.

TikTok Instagram Reels YouTube Shorts Custom entries Local schedules Optional presets

Install locally

Try it before the store listing is live.

  1. Download or clone the repository.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Click Load unpacked and select the project folder.
